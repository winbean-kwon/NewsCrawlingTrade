# NewsCrawlingTrade

이 프로젝트는 나스닥 관련 뉴스를 실시간으로 크롤링하고, 기업명을 추출해 해당 종목을 시장가로 자동 매수/ 매도하는 프로젝트입니다. 텍스트 요약 및 키워드 추출 기능도 추가하였습니다.

## 주요 기능

- **뉴스 수집 및 종목 추출**
  - 나스닥 페이지에 올라오는 나스닥 관련 최신 뉴스를 크롤링합니다.
  - 뉴스 제목에서 기업명을 추출하고, Yahoo Finance에서 해당 기업의 종목코드를 가져옵니다.
- **뉴스 요약 및 키워드 분석(테스트용)**
  - TextRank 알고리즘을 사용해 기사 내용을 요약하고 주요 키워드 추출
- **중복 뉴스 방지**
  - 이미 크롤링한 뉴스 제목은 check_list.csv에 저장하여 중복 실행 방지

## 방향성

1. 호재로 해석되는 키워드로 뉴스를 크롤링하여 매매 (ex. 임상성공)
2. 뉴스 전문을 크롤링하여 긍정 부정으로 분류 목표 ([FinanceSentimentCorpus](https://github.com/winbean-kwon/FinanceSentimentCorpus)에서 구현하였습니다.)

## 과정

1. nasdaq 페이지에서 특정 키워드(급등 예상)를 검색 후 제목에서 기업명 추출 (이전에 추출한 기업명과 동일할 시 새로운 뉴스 올라올때까지 반복)
2. yahoo finance에서 검색 후 상장된 회사인지 체크
3. 상장된 회사들만 매수, 나머지 상황은 다시 1번 반복

## 한계

1. 키워드가 한정적
  - 제목에 무조건 기업 이름이 있어야함
  - 무한루프를 돌기때문에 매일같이 뉴스가 올라오는 키워드가 아닌 것들은 효율성이 떨어짐
2. 뉴스가 실시간 데이터인지 확인이 불가능 (nasdaq 페이지에서 늦게 올라와 주가에 반영된 경우)
